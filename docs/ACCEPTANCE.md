## 四、核心设计约束（务必保持）

1. **主动引擎不调 LLM**：规律学习用 Cypher 聚合 + 统计，成本可控。
2. **反馈闭环是必需件**：没有它，主动式助手会被用户关通知。
3. **Java 不拉起 Python**：进程生命周期收口 Tauri sidecar。
4. **confidence = 0.35·consistency + 0.25·freq + 0.25·recency + 0.15·feedbackScore**，阈值 0.60。
5. **集成事件稳定 eventId**：`source:<自然键>`，内核 MERGE 幂等兜底。
